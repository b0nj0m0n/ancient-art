# Reference art: Japanese battle and landscape prints

Mood and style reference for the painted-paper look described in `docs/design.md`
§2 (art direction). **These images are reference only.** Don't ship them in game
builds. Draw original art informed by them.

- 47 images, resized to 2560px on the long edge (JPG quality 85). Ben keeps the
  full-size originals locally.
- `image-from-rawpixel-id-*`: public-domain scans from [rawpixel](https://www.rawpixel.com/).
- `master-pnp-jpd-*`: Japanese prints from the Library of Congress
  [Prints & Photographs Online Catalog](https://www.loc.gov/pictures/collection/jpd/).
- File names match the originals, so you can look up each source by its ID.
