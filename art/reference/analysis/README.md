# Phase 1 analysis of the core figure prints

Made for the art pipeline (vector parts + diffusion surface pass).

- `style_bible.json`: style clusters, shared drawing conventions, palette, gaps.
- `palette.json`: pigments by hue family (light / mid / dark) and neutrals, pooled from the 17 core prints.
- `records/NN.json`: one per print (index matches `../manifest.csv`): subject, themes, style notes, and each figure's bounding box, view, facing, kit and training use.

Figure crops, contact sheets and the scripts that made these files live with the full-size masters, outside the repo (`ancient-art-reference/_phase1/`). Bounding boxes are by-eye estimates. Reference only: none of this ships in the game.
